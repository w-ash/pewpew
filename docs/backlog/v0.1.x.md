- [x] **Pacing-jitter soak — desktop datapoint (§12 item 13)**
    - Effort: S
    - What: 10-min soak of a paced 16.7 ms loop, cadence histogram (p99) with GC active + an audio thread running, against ADR-010's pacer and its rejected alternative.
    - Why: ADR-010's silent dependency — device interpolation is hostage to host cadence consistency.
    - Dependencies: None (pure host code)
    - Status: Completed (2026-07-27)
    - Notes: `bench/bench_pacing.py`; report `bench/results/pacing-2026-07-27-mac-m5pro.md`. PASS on this host — p99 cadence error 3.78 ms, 1 of 35 995 intervals off by a frame, 59.99 fps; residual jitter is the OS sleep timer, not CPython. The rejected compensated-sleep pacer measures 51.17 fps / 8.8 s drift per minute, turning ADR-010's code-read rejection into a measurement. A spin variant reaches p99 0.003 ms if item 11 ever needs it. A 2026-07-26 run was withdrawn after review found a skip-ahead off-by-one and a thermal confound; these are the corrected figures.
